# BrightNotes

Bright 的知识总结与洞见 —— decks、笔记与文章。

## 说明

这个仓库用来公开发布我整理的学习总结、演示文稿（HTML deck）和文章。

## 如何添加内容

把要公开的 `.html` 文件放到本目录，然后：

```bash
git add .
git commit -m "add: <内容名称>"
git push
```

## 开启网站（GitHub Pages）

有内容后，到仓库 **Settings → Pages**，Source 选 `main` 分支、根目录，保存。
几分钟后内容就能通过网址访问：

```
https://zl220.github.io/BrightNotes/<文件名>.html
```
